# Minecraft Bedrock Phone Mod

Bedrock PocketPhone is a Minecraft Bedrock mod and Script API add-on that adds a persistent in-game smartphone interface with apps, contacts, messages, notes, reminders, calculator tools, settings, and other local phone features for Bedrock 1.21.50 or newer.

## Install

1. Run `python package_addon.py` from the project folder. On Windows, you can also run `py package_addon.py`.
2. Open the generated `PocketPhone.mcaddon` file with Minecraft Bedrock.
3. Create or edit a world and enable the imported PocketPhone behavior pack.
4. Enable Script API support if your Bedrock version requires it.
5. Join the world.

## Use

1. Type `phone` in chat to open the phone.
2. The phone also opens shortly after a player first joins the world.
3. Select apps from the paged home screen.
4. Use Contacts to save names and phone numbers.
5. Use Phone to simulate calls to saved contacts.
6. Use Messages to save simulated outgoing messages.
7. Use Notes and Reminders to store personal entries.
8. Use Camera to save caption-based photo entries, then view them in Photos.
9. Use Settings to change wallpaper, dark mode, brightness, and volume values.
10. Use Dock / Organize to choose which installed apps appear in the dock.
11. Use Store to install additional in-game app entries.
12. Player phone data and installed apps are saved with Minecraft dynamic properties.

The Camera stores captions rather than real screenshots. Calls, messages, weather, browser searches, and other external services are simulated locally. The add-on cannot access the device camera, microphone, internet, external media, native Wi-Fi, cellular, Bluetooth, flashlight, battery, or notification APIs.
